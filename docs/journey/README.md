# Build journey

This directory is the chronological record of Desky's development. Capture
successful experiments as well as failures, unexpected behavior, and changes of
direction.

Create entries using the format:

```text
YYYY-MM-DD-short-title.md
```

Each entry should include:

- Objective
- Setup and components
- Procedure
- Measurements or observations
- Photos, videos, diagrams, or logs when useful
- What worked
- What failed
- Safety or privacy concerns discovered
- Decision and next experiment
