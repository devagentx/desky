# Architecture decision records

Use short architecture decision records for choices that are expensive or
difficult to reverse.

Name each record:

```text
NNNN-short-decision-title.md
```

Suggested template:

```markdown
# NNNN: Decision title

Date: YYYY-MM-DD
Status: Proposed | Accepted | Superseded

## Context

What problem or constraint requires a decision?

## Options considered

What realistic alternatives were evaluated?

## Decision

What was chosen and why?

## Consequences

What becomes easier, harder, more expensive, or more constrained?
```
